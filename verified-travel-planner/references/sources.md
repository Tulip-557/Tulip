# 信源名单

**这是个人资产，本 skill 不预置任何白名单。**

用平台榜单起步，旅途中刷到靠谱的探店/攻略内容再补进来。

---

## 维护方式

补充时记录：

| 字段 | 说明 |
|---|---|
| 平台 | 小红书 / 抖音 / B站 / 点评 |
| 账号名 | 公开显示名 |
| **账号 ID** | ⚠️ **必记**——只记名字会认错号 |
| 粉丝量 | 用于交叉验证 |
| 领域 | 该账号擅长的地域/品类 |
| 可靠性 | high / medium / low |
| 备注 | 认号要点 |

> ⚠️ **必须记账号 ID，不能只记名字。**
> 近名假号很多——曾有"大东来了"冒充正主，实际是发西安团购券的号。
> 认号方法：读平台用户卡的「账号ID + 粉丝量」，与内容形态一起比对。

## 使用规则

1. **信源名单不是证据**——账号说的内容仍需按 `evidence-rules.md` 定级
2. **命中信源的店「用透」**——收录的店在美食清单或备选池里必须有自己的行，不能只躺在情报卡
3. **纯流量网红店需交叉验证**——防充值（看评论区本地人评价 + 地图复核）
4. **名单里的账号内容**，票价/营业时间/车次一律不可采信，那些必须回官方渠道

---

## 在情报回路里的位置

名单是阶段 3.5 的**三份可复用资产之一**（另两份是线索卡与玩法情报库），
角色是**采集起点**：开工先看名单里有没有对口账号，省掉一轮盲搜。

```
名单（谁值得看）──┐
                  ├─→ 阶段 3.5 采集 → 线索卡（机器可核）→ 阶段 4 路线
玩法情报库（已知结论）┘              └─→ 阶段 6 复盘 → 回流名单与情报库
```

**回流动作**：旅途中刷到靠谱内容 → 当场补进名单；行程结束复盘时 → 把
「跨行程仍然成立」的玩法/时节/机位追加进 `情报库/玩法情报_<城市>.md`。

## 找店心法（不依赖具体名单）

- **看食客**：本地人多不多
- **看年头**：开了多久
- **看评价**：先看差评，差评能接受才去
- **人多的一般没错**——不必非吃固定哪家
- **备选池要分层给足**：知名正餐 / 夜宵名店 / 本地宝藏苍蝇馆子 / 早餐小吃 / 酒店周边
  —— 知名店保稳定出品，宝藏店保本地里子，**都要推，选择权交给用户**
