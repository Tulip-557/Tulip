# 需求采集清单

阶段 0 用。逐项问清，**已知跳过，缺失用默认值并明确声明**。

> 默认值被静默应用 = 用户分不清是他说过的还是你替他定的。所以每个默认都要写出来。

---

## 基础项（每次必问）

| 项 | 问法 | 缺失时的默认 |
|---|---|---|
| 时间窗 | 哪天走哪天回？能否请假？ | 无默认，必须问 |
| 当前状态 | 还没出发 / 在路上 / 已到当地？ | 计划中（规划模式） |
| 人数结构 | ①几个人、什么关系 ②有无体力特殊成员 | 无默认，必须问 |
| 交通方式 | 自驾 / 高铁 / 飞机 / 卧铺（可组合） | 无默认，必须问 |
| 预算档位 | 大概什么水平？ | 中档 |
| 硬约束 | 排除地区、去过的、忌口、体力上限 | 无 |
| 已计划前往 | 有没有已经定好要去的点？订票了吗？ | 无（留空） |
| 玩法取向 | 深度体验 or 特种兵暴走？ | 无默认，必须问 |
| 内容目的 | 纯玩还是要出内容？ | 要出 |
| 偏好锚点 | 出片/美食/避暑/人少/文化，排个序 | 不设权重 |

---

## 人数结构判定两问（决定后续所有模式切换）

**第 1 问：几个人、什么关系？**

- 兄弟局 → 玩得爽 + 性价比，可叠加特种兵，深夜局常态化
- 闺蜜局 → **出片 + 氛围**，拍照好看的店 ≥ 好吃的店，互拍是核心需求
- 情侣 → 两人时光，浪漫时段 > 打卡数量，景观房是加分项
- 家庭带娃 → 娃的体验决定成败，午睡刚需
- 家庭带长辈 → 省力 + 舒适，叠加省力慢游轴
- 一人行 → 独立自主 + 安全，自设疲劳红线
- 混合 → 按最低体力/最低意愿者取齐

**第 2 问：有无体力特殊成员？**

有（长辈 / 腿脚不便 / 带娃）→ 触发省力慢游轴。

> 统称「省力慢游」，不用"年老体弱"类标签——说的是方案属性，不是人的属性，谁用都不别扭。

---

## 同行者档案（非一人行必采）

| 项 | 为什么采 |
|---|---|
| 口味下限 | 决定餐厅档位与点菜分量 |
| 体力与作息 | 决定每日强度与出发时间 |
| 兴趣类型（自然/人文/美食/拍照） | 决定热度配比 6:3:1 的具体分配 |
| 自驾几人能开 | 轮换需要，单司机要控全天里程 |
| AA 规则 | 决定预算表是按人均还是按人列 |

**核心原则**：行程完成度 = 全队最低意愿者的完成度。

> 实战教训：两队友一个脚伤、一个对人文无感，夜景连打全废。

---

## 作息采集（所有行程必采）

**只问事实，不给人定型。** 就四句：

1. 全队一般几点起？
2. 有人能起早吗？
3. 有人晚上精神吗？
4. **有没有一定要在特定时段做的事？**（夜爬／拍星空／看日出／夜景亮灯／逛早市／赶海）

**没答默认 = 睡到自然醒。**

三代同游作息必不同步，**主线就低不就高**——能起早的去冲晨雾日出（入早起包），主线按最晚起的排。

---

## 一人行专属采集

- 是否首次独行
- 夜归安全底线（最晚走亮灯主干道路线）
- 报平安对象与频率
- 独行经验

> 一人行无人拉踩刹车，必须自设「疲劳红线」（日行步数上限 + 最晚回程时刻）。

---

## 省力慢游专属采集

- 连续步行上限（走多久必须歇）
- 台阶承受度（完全不能爬 vs 少量慢慢爬）
- 午休是否刚需
- 慢病与常用药（高血压·膝盖·腰 → 高海拔/高温/久站项目先过健康红线）
- 行动辅助（拐杖/轮椅/婴儿车 → 触发无障碍实查）

---

## 玩法取向追问（仅特种兵时追加）

- 体力自评（日行 3 万步 + 夜车，如实评估不强撑）
- 学生证是否在手（半价杠杆核心）
- 精确时间窗（早八约束、末班首班时刻）
- 夜车接受度（硬座/动车夜宿省房费 = 省钱第一杠杆）

---

## 输出：trip_request 结构化

采集完归一化成结构化请求，格式见 `data-contracts.md`。**校验后如果状态是 `NEEDS_CLARIFICATION`，一次性把缺的字段和冲突项全问完，不要挤牙膏。**

「同行者档案」与「作息采集」里问到的**饮食忌口/喜好、作息休息、兴趣**，
归一化进 `preferences` 字段（`diet` / `pace` / `interests`）——这是主路线个性化的落点：
- `diet` ← 口味下限、忌口
- `pace` ← 几点起、午休是否刚需、有没有固定时段要做的事
- `interests` ← 兴趣类型（自然/人文/美食/拍照）

> ⚠️ `preferences` 只放**用户自己说出口的**，不放任何推断——推断会冒充采集值。
> 用户没说的键不写（缺省 `{}` 进 `assumptions`），追问不猜。
